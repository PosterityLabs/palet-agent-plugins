# Palet

Connects your agent to [Palet](https://palet.so)'s hosted MCP server (`https://api.palet.so/mcp`) and adds five skills: design-on-canvas, code-to-design, design-to-code, design-system-on-canvas and review-and-fix. They all draw with Palet variables, never hard-coded colours.

Sign in with your Palet account on first use (`/mcp` in Claude Code). No API key is needed.
